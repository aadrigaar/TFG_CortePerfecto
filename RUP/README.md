# Corte Perfecto - Seguimiento RUP

Este directorio recoge artefactos vivos inspirados en la estructura de `pySigHor`, adaptados al alcance real del TFG Corte Perfecto.

El objetivo no es duplicar los capítulos entregables, sino dejar evidencia trazable entre requisitos, análisis, diseño, implementación y pruebas.

## Artefactos principales

| Artefacto | Propósito |
| --- | --- |
| [`99-seguimiento/trazabilidad-casos-uso.md`](99-seguimiento/trazabilidad-casos-uso.md) | Relaciona casos de uso con módulos reales, rutas, modelos y pruebas. |
| [`99-seguimiento/auditoria-diseno-implementacion.md`](99-seguimiento/auditoria-diseno-implementacion.md) | Comprueba que el diseño del Capítulo 3 se refleja en el código. |
| [`99-seguimiento/estado-casos-uso.puml`](99-seguimiento/estado-casos-uso.puml) | Dashboard visual de estado al estilo de seguimiento RUP. |

## Criterio de uso

- Los capítulos (`entregas/Capitulo1.docx`, `Capitulo2.docx`, `Capitulo3.docx`) son la memoria formal.
- `plantuml/` conserva los diagramas fuente versionables.
- `RUP/` deja la trazabilidad operativa del proyecto, igual que `pySigHor` separa artefactos vivos de entregables.
